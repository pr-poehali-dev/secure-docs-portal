# Инструкция по использованию Портала документов

## 🔑 Вход в систему

### Учетные данные по умолчанию

При первом запуске системы автоматически создаются три пользователя:

**Администратор** (полный доступ):
- Логин: `admin`
- Пароль: `admin123`
- Права: управление проектами, пользователями, может удалять документы

**Менеджер** (обычный пользователь):
- Логин: `manager`
- Пароль: `manager123`
- Права: создание, редактирование, архивирование документов (без удаления)

**Гость** (только просмотр):
- Логин: `guest`
- Пароль: `guest123`
- Права: только просмотр документов, без возможности изменений

⚠️ **ВАЖНО:** После первого входа обязательно смените пароли!

### Как сменить пароль

1. Войдите в систему под своим логином
2. Перейдите в раздел **"Администрирование"**
3. Найдите нужного пользователя в списке
4. Нажмите кнопку с иконкой ключа 🔑
5. Введите новый пароль (минимум 6 символов)
6. Подтвердите изменения

## 🌐 Размещение на хостинге

### Пошаговая инструкция:

1. **Скачайте проект**
   - В редакторе poehali.dev нажмите **Скачать → Скачать билд**
   - Или скачайте код и выполните `npm run build`

2. **Загрузите на хостинг**
   - Распакуйте архив
   - Загрузите содержимое папки `dist/` в корневую директорию вашего хостинга
   - Обычно это папка `public_html/` или `www/`

3. **Первый вход**
   - Откройте ваш сайт в браузере
   - Используйте учетные данные по умолчанию (см. выше)
   - Решите простой математический пример (капча)
   - Войдите в систему

4. **Безопасность**
   - Сразу после входа смените пароли для всех пользователей
   - Это критически важно для безопасности!

## ❓ Частые вопросы

**Вопрос: Забыл пароль, что делать?**

Ответ: Очистите localStorage в браузере:
1. Откройте консоль браузера (F12)
2. Перейдите на вкладку "Application" → "Local Storage"
3. Удалите ключи `admin_users` и `admin_users_version`
4. Обновите страницу - пароли вернутся к значениям по умолчанию

**Вопрос: После переноса на хостинг не подходят пароли**

Ответ: Это исправлено! Теперь при первом запуске на любом хостинге автоматически создаются пользователи с паролями по умолчанию.

**Вопрос: Могу ли я добавить своих пользователей?**

Ответ: Да! Войдите как администратор, перейдите в "Администрирование" и нажмите "Добавить пользователя". При создании выберите роль:
- **Администратор** - полный доступ ко всем функциям
- **Пользователь** - может создавать и редактировать документы (без удаления)
- **Только просмотр** - может только просматривать документы

**Вопрос: Данные пропадают после перезагрузки страницы**

Ответ: Система использует localStorage для хранения данных. Убедитесь, что в браузере не включен режим "Инкогнито" и не настроена автоматическая очистка данных.

## 📞 Техническая поддержка

Если у вас возникли проблемы с входом или размещением системы:
- Проверьте консоль браузера (F12) на наличие ошибок
- Убедитесь, что localStorage не заблокирован
- Попробуйте открыть сайт в режиме инкогнито
- Очистите кеш браузера
